# Shared glossary

| Term | Definition |
|---|---|
| Workspace | An ownership and authorisation boundary containing desks and a knowledge collection. It is not permission inferred from a URL. |
| Desk | A persistent learning pursuit centred on an intention. |
| Session | A bounded period of activity on a desk, with a saved return point. |
| Working surface | The small set of items currently in use, not every collected resource. |
| Shelf | Saved source and activity references available without being expanded. |
| Card | A versioned, addressable presentation object with a host-owned shell. |
| Note | A learner-owned reusable document with independent identity. |
| Note–desk link | A reference placing a note on a desk, with explicit tutor-read policy. |
| Task definition | Versioned instructions/questions; separate from the learner's answer. |
| Attempt | Learner-owned response to a specific task revision, with assistance context. |
| Worked example | A source- or tutor-authored demonstration; viewing is not an independent attempt. |
| Annotation | A learner-owned document fragment attached to a revision-aware target. |
| Tutor contribution | Generated support with retained origin, even after learner acceptance. |
| Evidence | An observation or assessed attempt, with provenance, time, assistance and uncertainty. |
| Knowledge graph | Typed concept relationships, not the visual page layout or a mandatory progression lock. |
| Learning route | A revisable sequence proposed for a goal and learner; not the whole concept graph. |
| Teaching plugin | A bounded interactive capability with input/state schemas, targets and permissions. |
| MCP App | An interactive interface associated with an MCP tool and mediated by an MCP Apps host. [M1] |
| Desk learning profile | Our proposed additional contract for learning state, semantic targets and persistence; not an MCP standard. |
| Change set | One atomic meaningful change with before/after revision pointers. |
| Checkpoint | A broader recovery snapshot; distinct from targeted undo. |
| Readable export | Human-readable notes and activity representations; may not preserve every interactive feature. |
| Workspace backup | A versioned restorable package, with private content and an explicit asset manifest. |
| Source-available | Source is inspectable under stated terms; commercial restrictions are incompatible with the OSI open-source definition. [L1] |

## v0.4 additions

| Term | Meaning |
|---|---|
| Concept level | Explicit umbrella/topic/subtopic/granular scope; not an edge, mastery level or Bloom target. |
| Relationship registry | Versioned definitions of allowed graph links, their direction and validation. |
| Global navigation | Destinations outside a particular desk; same registry in sidebar/rail/mobile drawer. |
| Desk tabs | Contextual views of the current desk; desktop tabs/mobile bottom bar preserve object identity. |
| Decision layer | Optional bounded model-assisted classification/routing behind deterministic policies; not a second tutor. |
| Provider confidence | Provider-defined statistical output; not permission, truth, calibrated learning mastery or necessarily comparable across providers. |
| Single-view review | One screen, viewport, theme and state per visual cycle, then human review before the next. |
