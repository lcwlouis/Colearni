## Open decisions

Use OPEN_QUESTIONS.md. The frontier is not empty, but unresolved deployment/legal/pilot details do not require another broad interview before exporting plans or testing layouts. Never convert a proposal into an accepted decision merely because an image contains it.

## Change procedure

Record ID, prior/new rule, reason, impacted contracts/stories, migration implications and reviewer. v0.3 superseded the v0.2 plaintext-only editor placeholder and desk-local note identity. v0.4 retires all previous mockups and supersedes multi-option visual generation with single-view review; it adds explicit graph and mobile requirements. Contract version 2 is a draft migration target, not a running-system migration. No repository licence is adopted by this register.
