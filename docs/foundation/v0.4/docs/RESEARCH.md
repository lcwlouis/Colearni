# Bounded agentic research

## Purpose

The learner can begin with a broad intention; documents are optional inputs. Research supplies enough credible material to begin and fills specific gaps during learning. It does not automatically generate a giant syllabus or every prerequisite course.

## Workflow

Goal/current gap → check existing authorised desk sources → formulate a minimal query → search permitted providers → inspect useful passages → record provenance/access → choose limited support → place resources on shelf → introduce what is needed now.

A research worker can revise queries and follow promising evidence within a bounded job. The tutor remains responsible for the teaching move. Separate research and instruction responsibilities without requiring an autonomous agent team.

## Output record

Record source identity, URL, title, retrieval time, access level, relevant locator, selection reason, relation to the goal, and whether full content or only a snippet/abstract was inspected. Distinguish source claims, broader background and generated synthesis. Contradictions and uncertain quality should remain visible. Do not treat a citation URL as proof that it supports the claim.

## Controls

Global limits include requests, fetched bytes, time, tokens, provider spend and retries. Choose initial numbers in a measured implementation task, not as pedagogical facts. Provide cancellation and partial results. Avoid duplicate fetching; cache revisioned evidence with current permission checks. A failed search returns uncertainty and alternatives, not fabricated sources.

## Privacy and network policy

Tutor-read permission is not permission to disclose private paragraphs to a search provider. Pass a minimum necessary research brief. Seek explicit approval for sensitive material. Do not give the research worker the whole notebook. Credentials stay in a trusted service. Record outward data categories for inspection without logging secrets or complete private prompts by default.

Validate URLs, redirects, MIME types, file sizes, extraction cost and allowed destinations. Protect server-side fetches against private-network/metadata-service access and untrusted parsers. Retrieved content is task data, never an instruction source. Returned links cannot register tools or install plugins. [R9]

## Source rights

Preserve access/licence metadata. A learner having local access does not grant public redistribution rights. Private source-derived summaries, quizzes and examples stay private unless a deliberate sharing review permits them. An abstract-only source remains marked as such. Public educational use does not automatically make source content openly licensed.

## Prototype and test

Use deterministic synthetic results: relevant source, duplicate result, abstract-only result, failure/cancel and uncertain claim. Review shelf placement and reasons for selection before integrating a live provider. A small starting set should help the learner act rather than create a reading backlog.
