# E0 — optional shared-editor evaluation

Read AGENTS.md, docs/NOTES_AND_ACTIVITIES.md, docs/MOBILE_INTERACTION.md, docs/NOTES_CONTEXT.md and docs/INTERACTION_CONTRACT.md.

Evaluate at most two appropriately licensed editors against one synthetic note, one worksheet response and one worked-example annotation. Test visual editing/Markdown shortcuts, desktop toolbar, selection-based mobile formatting with an accessible Format/Insert fallback, IME, keyboard/screen-reader operation, stable block IDs, reference anchoring, save/revision conflicts and realistic export round trips.

Do not claim the web app can freely customise every OS long-press menu. Use an unstyled bounded harness, not a full notebook or invented design. Mark device tests unverified if no target devices are available. Agent writes to learner documents are forbidden. No live model calls or private data. Recommend an internal content format only from findings; Markdown export must disclose unsupported semantics. Stop after the comparison/report.
